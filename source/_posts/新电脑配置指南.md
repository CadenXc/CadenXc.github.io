## 一、基础设置

- **用户名设置**  
  系统激活注册时建议使用英文用户名。某些开发工具对路径兼容性较差，含中文可能导致异常。

- **语言与界面优化**  
  - 添加英文语言包，方便中英文切换。  
  - 在任务栏设置中关闭“小组件”和“任务视图”，并隐藏搜索框，让界面更简洁清爽。  

- **系统优化**  
  - 将桌面路径迁移到 D 盘（或任意非 C 盘路径），减轻系统盘压力。  
  - 打开以管理员身份运行的 PowerShell，执行以下命令关闭休眠功能，进一步节省 C 盘空间：  
    ```bash
    powercfg -h off
    ```
    > *个人观点：Windows 的休眠功能并不理想，平时直接关机更为稳妥。*

- **安全策略调整**  
  在微软电脑管家（Microsoft PC Manager）中，将除 C 盘以外的所有磁盘添加为“信任磁盘”或“排除项”，避免开发时频繁弹出安全提示。

## 二、D 盘目录结构

为了避免路径问题，所有文件夹名使用英文，并统一集中管理：

- `BrowserDownload`：浏览器下载目录
- `Caden`：我的英文名，放一些临时文件或杂项  
- `Code`：各类项目代码存放地  
- `NetworkDiskAndBtDownload`：网盘及 BT 下载文件存储  
- `Repositories`：存放从 GitHub 克隆下来的仓库  
- `Software`：软件下载目录  

---

## 三、软件安装与配置

### 浏览器

- 安装 **Google Chrome**，并将其和系统自带的 **Microsoft Edge** 的默认下载路径设置为 `D:\BrowserDownload`。

### 开发工具

- [Git](https://git-scm.com/)
- [Fork](https://git-fork.com/)：Git 图形界面工具
- [PowerShell](https://github.com/PowerShell/PowerShell)：推荐配合 [Oh My Posh] 美化终端
- [Watt Toolkit](https://github.com/BeyondDimension/SteamTools)：可用于 GitHub 下载加速

### 输入法与语言工具

- [小狼毫输入法](https://rime.im/)  
  配置 [雾凇拼音](https://github.com/iDvel/rime-ice)，并使用小鹤双拼方案
- [欧陆词典](https://www.eudic.net/)：好用的英文词典
- [PixPin](https://github.com/Pixpin/Pixpin)：截图标注工具，开源且好用

> 可以移步到这篇 [推荐博客](https://cadenxc.com/2025/06/02/%E4%BB%A3%E7%A0%81%E4%B9%8B%E5%A4%96%E7%9A%84%E6%8E%A8%E8%8D%90/)。

## 四、数据迁移建议

- **浏览器数据**：登录账号同步书签和插件即可。
- **项目代码 / 配置文件**：使用 Git 进行云端同步，方便管理。
- **敏感或私密数据**：不建议上传云盘，可通过 U 盘或局域网方式传输。
